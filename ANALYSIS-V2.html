SEC-001حرجحالة سباق (Race Condition) في استخدام الكوبون
📁 lib/coupons.ts:83⚙️ Race Condition
دالة useCoupon تقرأ الكوبون وتتحقق من usedCount ثم تزيد في خطوتين منفصلتين غير ذرّاتييتين. طلبان متزامنان قد يتجاوزان حد الاستخدام الأقصى.
الاستغلال: مهاجم يُرسل طلبَي تسوّق متزامنين بنفس الكوبون. كلاهما يجتاز الفحص قبل زيادة الآخر
الحل: استخدم Prisma transaction مع قفل أو updateMany شرطي يتحقق ويزيد في خطوة واحدة
SEC-002مرتفعتسريب بيانات الطلبات بدون مصادقة (IDOR)
📁 app/api/orders/track/route.ts👁️ IDOR
نقطة النهاية /api/orders/track تكشف: اسم العميل، بريده، المبلغ الإجمالي، بنود الطلب، وحالته لأي شخص بدون مصادقة.
الاستغلال: البحث بالبريد الإلكتروني أو رقم الطلب لجمع بيانات جميع العملاء
الحل: أضف مصادقة وتأكد أن المستخدم هو صاحب الطلب فقط
SEC-003مرتفعحقن الإعدادات الحساسة عبر API
📁 app/api/admin/settings/route.ts:14🛡️ Privilege Escalation
POST /api/admin/settings تقبل أي مفتاح/قيمة. المدير الفرعي يمكنه تغيير google_client_secret أو maintenance_mode.
الاستغلال: manager يُرسل body مع {google_client_secret: "controlled-by-attacker"}
الحل: تحقق من أن المفتاح موجود في SETTING_KEYS قبل الحفظ
SEC-004متوسطكوكي الصيانة بدون توقيع معمّي حقيقي
📁 middleware.ts:19🛡️ Weak Auth
قيمة الكوكي 'signed:1' مجرد نص ثابت. لا يوجد توقيع HMAC فعلي. في بيئة HTTP غير مشفّرة يمكن تزويره.
الحل: استخدم HMAC مع AUTH_SECRET: crypto.createHmac('sha256', secret).update('1').digest('hex')
SEC-005متوسطعدم وجود Content-Security-Policy
📁 next.config.ts🛡️ Missing Header
رأس CSP غير موجود. يزيد من خطر XSS وتحميل مصادر خارجية ضارة.
الحل: أضف CSP header: default-src 'self'; script-src 'self' 'unsafe-inline'; img-src 'self' data: blob:
SEC-006متوسطحذف الحساب بدون transaction ولا حذف ملفات
📁 app/actions/account.ts:89⚙️ Data Integrity
حذف الحساب بعدة عمليات متتالية بدون transaction. صور الإثبات (proofImage) تبقى على القرص بعد الحذف.
الحل: لُف في prisma.$transaction() واحذف الملفات بـ fs.unlink()
SEC-007متوسطAUTH_SECRET يُستخدم في بيئة التطوير بدون تعليق
📁 .env:9🔐 Secret Mgmt
ملف .env يحتوي على AUTH_SECRET حقيقي. لو نُشر بدون تغيير، أي شخص يوقع JWT tokens ويصبح أدمن.
الحل: غيّر المفتاح في كل بيئة نشر + أضف تعليق واضح
SEC-008منخفضحالة الطلب بدون مصادقة تسمح بالتخمين
📁 app/api/order-status/[id]/route.ts👁️ Info Disclosure
كشف حالة أي طلب بمعرفه دون مصادقة. يسمح بالتحقق من وجود أو مراقبة تغييرات حالة طلبات معينة.
SEC-009منخفضصور إثبات الدفع تبقى بعد حذف الحساب (GDPR)
📁 app/actions/account.ts🔒 Privacy
بعد حذف الحساب، ملفات صور الإثبات في public/uploads/proofs/ تبقى على القرص. انتهاك محتمل لخصوصية المستخدم.
